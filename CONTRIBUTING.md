# Contributing

Run `npm ci`, `npm test`, and `npm run build` before opening a pull request.
Use `npm run test:e2e` for input, UI, storage, or gameplay changes. Include the
browser and input method used to verify the change. Keep fixtures and footage
free of private data.

The Dorothy mark has [separate branding rights](public/licenses/Dorothy-branding.txt).
Include licensing details for any new assets or dependencies.
